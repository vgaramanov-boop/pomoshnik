# Помощник

Удалённая помощь родным: просмотр экрана, управление, запись экрана, передача файлов. Аналог AnyDesk, своего сервера нет.

- **Сайт для iPhone/iPad:** https://vgaramanov-boop.github.io/pomoshnik/ — откройте в Safari → «Поделиться» → «На экран „Домой“».
- **Windows 10/11 и Mac:** готовые программы — в разделе Releases (или у автора в архивах).

## Структура
- `docs/` — веб-версия (публикуется через GitHub Pages).
- `src/app/` — программа на Electron (общий код интерфейса в `src/app/ui`).
- `src/web/` — дополнения для веб-версии и сборщик `build-web.py` (`python3 src/web/build-web.py docs`).
- `src/test/` — проверки с локальным ретранслятором.

Соединение: WebRTC напрямую между устройствами; знакомство через PeerJS Cloud и публичные MQTT-брокеры, сообщения зашифрованы (ECDH P-256 + AES-GCM).
